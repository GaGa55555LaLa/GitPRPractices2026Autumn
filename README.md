## Git 發送 PR 練習

閱讀完本專案的架構後，根據自己的**學號**，在程式碼中正確的位置，插入你的學號，與你想說的話 (像是對本課程的期望之類的)，發送一個 PR 到本專案，合併成功即完成作業。

### PR 發送規則

- 助教會按照 Github 賦予的順序編號開始合併
  - 前面的 PR 檢查失敗或有衝突時，會跳過該 PR
- 必須通過所有 CI 自動檢查
- 必須新增恰好一筆自己的資料
  - 只能在對應的作業檔新增自己的資料，不得修改他人資料、檢查程式或 CI 設定
- 必須剛好只有一個簡單變更 commit (不可以出現像是 merge 節點之類多餘的東西)
  - 如果有人在你的前面修改了相同檔案，可能會導致變更衝突，你需要使用 git rebase 來練習更新變更基底
- Commit 標題必須是 `[Add] 你的學號`，如 `[Add] 123000000` 或是 `[Add] x112001`

### 編譯與檢查

請依 `hash-viewer` 顯示的數字修改 `src/homework/hw00.cpp` ~ `hw09.cpp` 中對應的檔案，並用 `V.emplace_back("學號", "想說的話");` 加入資料，並保持**學號遞增**。每個檔案已經有一筆學號作為範例。

需要 GNU Make 與支援 C++17 的 C++ 編譯器，Windows 可使用 w64devkit。

```sh
make              # 編譯 checker 與 hash-viewer
make check        # 編譯並執行所有作業檢查
make clean        # 移除 build 目錄中的編譯產物
```

編譯結果會放在 `build/`。

### 格式要求與 CI

專案使用 clang-format **18** 檢查格式。送出 PR 前請執行：

```sh
make format        # 自動整理 C++ 原始碼與標頭檔
make format-check  # 檢查格式，但不修改檔案
make -j2 all check # 建置兩個工具並檢查所有學號
```
